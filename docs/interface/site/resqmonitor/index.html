Monitor prediction accuracy, costs and response times

Review predictions against actual outcomes: accuracy, outcome coverage, confidence, cost per correct result, latency and changes from a baseline. Calculations remain with the Python program.

python3 -m resqmonitor · from the repository checkout

Interface preview

This mock-up shows what a browser interface for the tools could look like. It is not yet connected to the Python tools and does not run their calculations. To use the tools, download and run the code from the respective GitHub repository: github.com/dr-opoku/resqmonitor

The code is available under a non-commercial license. Commercial use requires a separate license.

01

Inputs

Required current records and an optional baseline in the same format.

csv – current records

ID, prediction, actual outcome; optional confidence, cost, latency_ms, group

--baseline – comparison records

ID, prediction, actual outcome; optional confidence, cost, latency_ms, group
