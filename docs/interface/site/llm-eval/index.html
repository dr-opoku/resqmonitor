Compare LLM configurations on a defined set of test cases

Compare model responses against a fixed benchmark and explicit acceptance rules. Results apply to these test cases, not a universal model ranking; no winner is selected automatically. Evaluation remains with the Python program.

python3 -m llm_eval · from the repository checkout

Interface preview

This mock-up shows what a browser interface for the tools could look like. It is not yet connected to the Python tools and does not run their calculations. To use the tools, download and run the code from the respective GitHub repository: github.com/dr-opoku/llm-eval

01

Benchmark

Task, policy and test cases (schema_version 1.0; 1–500 cases; at least one boundaries case expecting reject).

benchmark_sha256 (canonical JSON as in llm_eval.contracts.fingerprint): · Edits change the fingerprint; existing runs will no longer match.

Benchmark details

policy – sample acceptance rules

Response contract

  • decision: accept | review | reject
  • fields.supplier: nonempty string or null
  • fields.units: integer 1–1,000,000 or null
  • fields.unit_price_eur: number 0–1,000,000 or null
  • evidence_ids: unique, nonempty strings
  • reason: nonempty string
  • Accepted = strict_json ∧ schema_valid ∧ fields_match ∧ decision_match ∧ evidence_match. The reason text is not evaluated.
