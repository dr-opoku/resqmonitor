# Project status, support and rights

This is a small reference implementation. Maintenance is best effort; there is no service-level agreement, production certification or guaranteed response time. Checked behavior and remaining limits are recorded in [the review](REVIEW.md).

## Usage rights remain an owner decision

No redistribution or usage license has been selected. Source availability and the runnable examples do not themselves grant permission for commercial use, research use, redistribution or incorporation into another product. Contact the repository owner before relying on a permission that has not been granted. This status note does not grant a new license or change existing rights.

Before release the owner must decide:

- permitted individual, academic and organizational evaluation;
- the boundary between noncommercial research, internal company use and commercial exploitation;
- modification, redistribution and contribution rights;
- any separate paid commercial agreement and delivery mechanism.

A future commercial license or checkout can be linked from the README once actual terms and fulfillment exist. There is currently no purchase flow or commercial license offer in this repository.

## Feedback and contributions

Report reproducible defects or documentation problems through the repository's Issues where enabled, or the existing owner contact channel. Include Python version, command, expected/actual behavior and the smallest synthetic reproduction. Never attach customer data, private model captures, access tokens or private platform material.

Discuss proposed contributions before opening a pull request while contribution rights remain undecided. Do not assume this repository accepts code under an unspecified license.

For a suspected security issue use GitHub private vulnerability reporting if available, otherwise an existing private owner channel. Do not publish secrets or exploit details in a public issue. No private reporting address or response guarantee is implied.
